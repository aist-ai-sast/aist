# Azure DevOps work-item links

AIST can associate a finding with an Azure DevOps work-item URL. The link keeps
the title, URL, and status entered in AIST.

Automatic Azure DevOps status synchronization is not currently supported. The
link therefore behaves like a manual remediation reference and changes only
when an AIST user updates it.

See the [work-item support matrix](../product/work-item-links.md#supported-providers)
and [work-item link lifecycle](../product/work-item-links.md).
