# Linear work-item links

AIST can associate a finding with a Linear issue URL. The link keeps the title,
URL, and status entered in AIST.

Automatic Linear status synchronization is not currently supported. The link
therefore behaves like a manual remediation reference and changes only when an
AIST user updates it.

See the [work-item support matrix](../product/work-item-links.md#supported-providers)
and [work-item link lifecycle](../product/work-item-links.md).
